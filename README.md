# Bullet Hell

A sleek bullet hell game built with **p5.js** and **JavaScript**. This project focuses on delivering smooth, enjoyable mechanics while keeping the game approachable and fun rather than forcing an unforgiving challenge.

---

## Key Features

* **Custom Artwork:** All visual assets, sprite designs, and game art created entirely from scratch.
* **Easy gameplay:** The game is meant to be good to spend a small amount of time without too many frustrations.

---

## Challenges & Solutions

* **Balancing Difficulty:** Bullet patterns were tuned through continuous playtesting to ensure they feel fair and readable rather than overwhelming.
* **Iterative Playtesting:** Frequent test loops helped identify frustrating bottlenecks and refine dodge windows.
* **Collision Math:** Implemented precise hitboxes to ensure fair player-to-projectile interactions without feeling cheap.

---

## Technologies Used

* [p5.js](https://p5js.org/) - Creative Coding Library
* JavaScript (ES6+)
* HTML5 / CSS3
* Piskel - Pixel Art/Sprite Editor

---

### **Results**
* Successfully delivered a **playable prototype** featuring core gameplay loops, original visual art, and accessibility-first design choices.

### **What I Learned**
